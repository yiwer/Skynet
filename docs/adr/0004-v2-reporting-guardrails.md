# 用可核查的报表与使用能力评估支持辅导

管理者需要从会话中了解员工怎样使用 Coding Agent、哪些方式值得学习以及哪些方面需要辅导。用户于 2026-09-28 确认 [PRD v2.0](../requirements/PRD-v2.md) 的报表、对话视图、活动记录、组装审计和使用能力评估；本记录整理这项已确认决定，不表示用户已经审阅本次文档修订。

V2 允许对已采集会话中的使用方式与效果给出六个维度、综合指数与等级。评估采用固定锚点、任务类型校正、样本与可信度门槛，定位为辅导参考；每项结论能展开到指标、原文与版本。产出转化按团队同类任务基线校正，基线随结果版本保存；团队维度得分中位数只作为画像中的参照。原件、确定性事实、模型推断和人工复核分别保留，未知字段不作零值，推断可更正并重算。

报表、Web、MCP 和导出使用同一个指标服务。新增能力沿用 V1 的模块化单体和独立分析 Worker，认证后的全部数据共享查看沿用 ADR-0002，完整原件存档与系统分析隔离分别沿用 ADR-0001、ADR-0003。选择这条路线，需要维护指标、分析、评估参数及输入基线的版本，并验证全量重算与增量结果一致。

被否决的做法包括整体绩效分、名次与 Top / Bottom 榜单、同事间百分位排名、按指数或指标排序的人员列表或导出、工时折算与考勤、根据结论自动发通知或触发人事动作、用户自定义权重。人员与等级组内按姓名排列，员工和管理者可追加复核备注。会话明细可以排序，三套系统权重方案的变更按模型版本发布。

## 实施与发布顺序

2026-10-03 用户直接要求“开始实现V2”。据此在已有 V1 数据链上先开发 V2，并将 S0 文档修订随首批实现交付；原先“G2/G3 未通过时仅做 S0 后停止”的开发顺序被本轮指示覆盖。本记录不声称 S0 修订文本已经签收，也不将开始开发解释为真实验收通过。
