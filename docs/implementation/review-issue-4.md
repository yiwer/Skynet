## 集成检查补充

PostgreSQL 镜像初始化会临时启动仅接受 socket 的服务器。测试及 Compose 的 `pg_isready` 未指定 TCP host，可能在最终 TCP 服务启动前误报就绪；须明确探测 `127.0.0.1`。同时保证浏览器启动或关闭失败时仍清理测试容器。
