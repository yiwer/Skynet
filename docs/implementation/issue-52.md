# #52 试点参数复核：离线资料生成

**状态：工具已实现，真实试点、参数建议和用户确认未完成；本票不能关闭。** 此工作只为获授权的复核提供可重复资料，不替代 PRD-v2 的评估全员开放门槛。

## 生成资料

`npm run calibration -- <样本清单.json> <新的输出目录>` 读取现有公开固定 API：员工一览导出、逐人评估导出、用量导出和模型参数。所有请求为带个人读取凭据的 HTTPS GET，不读取原始会话，不启动分析 Worker，不发布参数，不写平台数据库。

清单格式：

```json
{
  "origin": "https://skynet.91boy.cn",
  "peopleVersion": "替换为固定员工一览的64位版本",
  "employeeIds": ["替换为本次明确纳入的员工UUID"],
  "sample": {
    "kind": "pilot",
    "label": "替换为试点登记名称",
    "authorizationReference": "替换为授权范围记录的位置",
    "knownBiases": ["填写客户端覆盖、时间与样本选择的已知偏差"]
  }
}
```

自动化仅使用 `kind: "synthetic"`、`authorizationReference: null`。实际试点必须提供授权引用，但工具不会将填写引用解释为已经核验授权或已获模型发布确认。清单必须明确列出员工，不支持默认全员。固定员工一览可在其导出中取得；工具拒绝缺失人员、重复人员和来源版本不一致。

运行前在当前进程环境设置 `SKYNET_READER_CREDENTIAL`；不要写入清单或命令行参数。工具不输出凭据；拒绝站点 URL 内嵌凭据、路径、查询或重定向，不关闭 TLS 校验。单份远端资料及最终资料各限 32 MiB，人数限 1000。输出目录必须不存在，避免覆写旧材料；`manifest.json` 最后写入，标识完整生成。

输出为：

- `calibration.json`：明确样本的六维/综合指数分布（未知单列）、可信度、待定分子分母、客户端类型覆盖、时间范围、已知偏差、完整固定模型参数、逐人固定评估及原句证据链接。人员按姓名排列，不含人员排名；不写入未选择人员资料。
- `review.md`：可阅读的分布与逐人核查入口、异常核查/建议/确认的待填项。没有原句依据时不自动称为异常，也不自动建议调参。
- `manifest.json`：输入登记、资料版本、文件 SHA-256。相同固定输入可重复生成相同内容。

固定用量导出能说明客户端类型及来源完整性，不能证明未接入设备和客户端具体版本。实际试点登记须另外核对这些范围。不要把“已知的得分”数量当成高可信度数量。

## 复核与版本发布流程

1. 取得参与者/材料/时间/客户端授权范围与登记，核查与清单一致。保留同意记录的位置；不把平台读取凭据视为试点签收。
2. 生成资料后保留原目录；复制 `review.md` 为另外的复核记录，填写异常个例、固定评估/原句、样本偏差和参数建议，避免修改已校验文件。
3. 对每项建议列出旧值、新值、依据和影响，包括维持现值的决定。提交用户确认具体资料版本和参数差异。当前没有该确认，也没有真实分布报告。
4. 若批准变化，修改 `assessment-model.ts` 的整体参数对象，经代码评审与公开回归后发布新代码版本。锚点、门槛、权重、等级、可信度和建议库一起参与模型版本哈希；不修改已有模型/评估行，也不开放用户自定义参数入口。
5. 用同一明确试点范围生成新资料包。比较旧/新模型版本、原始指标与基线版本；来源改变时同时列明，不能把数据变化的影响归因于模型参数。固定旧评估仍可查询。确认参数复核完成后，再单独记录全员开放验收。

该流程不自动记录“用户已确认”，也不启用生产付费分析或发送通知。尚缺实际参与者和授权范围、时间/客户端覆盖登记、真实复核与参数建议、具体参数决定；Qwen 凭据私人路径、模型 ID、预算及真实付费运行证据仍待用户提供。
