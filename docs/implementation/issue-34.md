# #34 同源、可重算的基础用量

2026-10-04。本票的指标链已完成：通过设备上传原件形成持久输入投影和固定报表版本，再由 HTTP、Web、OAuth MCP 与 JSON 导出读取同一结果。

## 指标与版本

- 指标口径升级为 `recorded-metrics-3/native-recorded-statistics-1`。用户轮次排除 Claude 明确标记的摘要/元消息，以及单个完整的机器环境封套；混合用户正文或多个封套仍计作用户提交。证据原件与既有固定版本不改写。
- 输入投影以快照 ID、原件哈希、归属修订、证据解析器、统计提取器、完整性版本和材料 ID 标识；保存原生用量记录、完整性结果及排除的用户行。新增快照/归属/解析版本形成新投影，已存在输入复用持久投影。
- 每次实时查询仍读取并校验所用原件哈希；物化不掩盖当前原件缺失或损坏。`POST /api/metrics/recompute` 绕过全部输入投影，从原件重新抽取；同值结果复用相同固定版本。原件暂不可用时实时查询与重算报告缺口，旧固定版本仍可读取；恢复原件后得到原版本的相同数值。
- 原件事实、员工/项目归属、谱系去重与报表保存处于同一个 `REPEATABLE READ` 事务。不同范围并发触及相同投影时，序列化竞争最多重试三次完整事务，避免把竞争误报为原件缺口。
- 已知输入/输出总额继续保留已确认部分。新增每日 `tokenTrend` 只包含所选范围内输入和输出均已知的会话；未知会话单列，不以零点或部分用量进入趋势。已知零仍是零。固定历史响应可缺少这个新字段，客户端保守使用历史完整数值。

## 公开产品入口

报表实时范围仅为本周、上周、接入至今，可叠加员工、Agent 和项目。任意 `custom` 实时范围返回 400；既有自定义范围的固定 `version` 可继续通过原 HTTP/MCP/导出入口读取，禁止借旧版本重算新范围。

V1 团队日期矩阵改用 `/api/team-coverage/metrics?date=YYYY-MM-DD&view=day|week`；日期/七日窗口由服务器确定，仍调用同一个指标服务。没有开放新的任意日期报表。原件日归期、仅有 Token 而无业务消息的日期、项目标签后续变化、恢复前缀去重均沿用既定语义。

用量页保留三种范围、整页筛选、完整固定版本导出和原件重算。页面显示北京时间范围与数据截至时间，指标口径收在可展开区域。未知值与未知会话数可见；员工柱形和每日柱形可通过键盘聚焦读取提示，Escape 关闭提示，每张主图可切换表格。趋势在未知位置断开，不补零，也不跨过未知位置连线。
