状态：三种来源的合成公开 API / Web 流程已实现并通过；既有三个原生恢复回归已通过。**三客户端实际续用接入前会话的完整验收尚未完成，Desktop 正常 UI / hook 条件仍未通过。#8 和 G0 的真实客户端门槛保持开放。**

本票的 tracer bullet：原生目录中已有多条旧会话 → 接入时不扫描 → 宿主活动仅登记被继续的一条 → 首次从该原件开头上传 → 后续只上传校验过的新增字节 → 已认证读者看到历史上下文、来源日期与接入后活动 → 服务器重启后仍可导出包含全部历史和增量的原件及恢复包。

## 采集与增量协议

资格仍来自公开 `collector hook` 入口落盘的宿主信号。后台只读取已登记的 transcript 路径，不通过目录遍历或 mtime 发现旧会话。修改其他旧文件的 mtime 或内容不会使它们获得上传资格。hook 快路径沿用 #6，不读取原件、不计算哈希、不等待网络。

首次上传保存全部现存原件。后台在收到 `committed` 且哈希、长度匹配的响应后，持久化快照 ID、SHA-256 和长度。再次读取时仅在新文件更长、旧长度对应的前缀 SHA-256 与已确认基准一致时上传后缀。新增字节可以包含未闭合末行；服务器组装的完整快照保留这些字节，解析器只展示完整的已识别记录。

| 公开接口 | 行为 |
| --- | --- |
| `PUT /api/chunks/:hash` | 按设备暂存并校验原件或增量字节；暂存不会出现在会话列表 |
| `POST /api/snapshots` | 提交已持久化的完整原件 |
| `POST /api/snapshots/append` | 接收 `manifest`、`baseSnapshotId`、`baseHash`、`baseByteLength`、`appendHash`、`appendByteLength` |
| `GET /api/snapshots/:id` | 返回该不可变快照的原件证据、分页内容及全量日期统计 |
| `GET /api/snapshots/:id/raw`, `/readable`, `/recovery` | 从选定完整快照导出；增量传输不改变导出的完整范围 |

增量接口验证基准已提交且属于同一设备、来源、原生会话，基准哈希和长度准确，后缀已持久化，组装结果的总长度和 SHA-256 与清单一致。完整新原件先持久写入，最后的快照数据库行才是原子提交点；旧原件和旧快照保持不变。错误的基准返回 409；长度或完整哈希错误返回 422；失败不发布新快照。同一增量重试返回同一快照 ID。

缺少本地已确认基准、前缀重写或文件截短时使用全量上传。服务器拒绝确认基准时，后台丢弃该基准引用并在本次运行回退全量；其他错误保留队列并给出错误状态。`collector status` 中 `uploadedBytes` 表示最近一次后台运行实际成功暂存的字节数，`appended` 表示该次通过增量接口提交的快照数；它们是传输指标，不是工作量。

本票仍限制单原件 8 MiB，并在内存中读取完整当前原件以核对前缀。传输已增量化，存储仍为不可变完整快照。多材料、大原件分块、明确代次与谱系由 #9 扩展；本票没有将单原件称为完整关联材料备份。

## 日期与确定性活动

新设备的接入时间由 PostgreSQL 在登记时记录。每次提交，服务器使用该设备的 `enrolled_at` 写入快照清单，客户端传入值不能覆盖它。升级前设备没有可证实的登记时间时保持空值；不使用升级时间、首次上传时间或文件 mtime 倒推。

证据中的来源时间保持原值，日期边界固定 Asia/Shanghai。页面分别展示设备接入、宿主登记、来源时间范围和服务器提交时间；原件中的时间只表示来源所记录的时间，不校准客户端时钟。

- 时间早于设备接入的已解析条目标为“历史上下文”。
- 时间不早于接入的条目标为“接入后活动”，按其来源日期归期。
- 缺失、无时区或格式无效的时间显示“来源时间未知”，内容仍可读，原件字节不改动。
- 旧设备缺少可信接入时间时显示“接入边界未知”，今日活动显示未知，不显示为 0。

“今日活动”只计算当天来源时间明确的接入后条目，展示用户轮次、工具调用和已解析条目数。Claude 同一原生用户消息的多个文本块只计一个用户轮次，工具返回不计为用户轮次。统计基于该快照全部已解析记录，不受页面 100 条分页影响；未知格式、未闭合行和时间未知内容不被当作确定活动。补传旧上下文和重试提交均不会增加这些计数。这里是单会话统计，不替代后续团队日周报告、Token、文件集合或实际工时。

旧快照仍可按其 ID 导出。可读导出添加来源时间与历史分类说明，并保留全部原件文本；原件和恢复包保留精确字节。恢复包记录服务器给出的接入边界，已有版本/OS 兼容性和全新目标目录检查继续适用。
