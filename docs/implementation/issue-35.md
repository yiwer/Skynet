# #35 组装审计与数据处理

本票沿用 PRD-v2 §4、US 72–84、AC-24/25 以及 2026-09-28 已确认的公开测试边界。实现基于不可变原件、已有事件归属和 #36 的持久投递回执，不增加文本相似度合并，也不改写原件或统计归属。

## 审计写入与读取

`archiveWriter` 在已有快照事务中写入初始组装记录；原件、事件归属、upload ID 绑定和审计共同提交后才返回 ACK。每次成功提交入口另记真实传输观察，因此丢失 ACK 后的重试不会变成第二份业务记录。分块入口在一条 SQL 内保存分块登记与本次接收观察；分块重复由该次插入是否命中已存在的 device/hash 确认，不从最终分块表行数倒推请求次数。

`assembly-1/origin-1` 保留来源原件清单、采集代次、实际分块组合、完成时间、主原件记录数、继承与重复身份数、原生 compact 派生记录数、谱系决定、侧链、缺口和规则版本。多块整件再增量追加时递归展开原组合，避免把多块基准误当成一块。相同文字且原生发生身份不同的提交保留为不同活动。主原件没有声明文件名时展示“主会话原件”，不编造本机路径。

初次独立会话的默认 `unconfirmed` 原始归属不等于待人工确认。只有已有归属服务提供真实重写、截断或无法验证关系的原因，才标记 `pending-lineage`。子材料继续以侧链保存；没有主会话资格的材料不增加基础用量。已验证恢复与续聊承接既有原事件，compact 原文仍可读，但基础指标不把派生摘要算作新用户提交。

- HTTP：`GET /api/snapshots/:id/assembly`、`GET /api/assembly`、`GET /api/assembly/export`。
- MCP：`read_assembly`、`list_assembly`，与 HTTP 使用同一服务。
- 明细响应最多提供各 20 个来源、缺口与侧链条目；后续页携带同一 `version` 与 `nextOffset`。导出为完整固定版本。
- 列表每次扫描 20 个快照，再应用状态过滤；即使本页为空，仍可沿 `nextOffset` 继续。支持来源、员工、提交日期和仅当前快照筛选。
- 旧快照按可验证原件与原归属重建审计，完成时间保持 `null`；没有入口观察的旧分块与重试次数保持 `null`，不将导入时间或来源时间冒充原处理时间。
- 版本只追加保存。动态读取核对当前原件可读性，存储缺失会显式产生缺口；固定版本保留当时观察，不声称是当前存储状态。
- 分块请求数是这些原件哈希实际收到的请求数；同一原件可能被多个快照引用，不能把多个会话的传输观察直接相加。业务去重仍按事件身份，不按这些传输数字计算。

## 处理链路与计时

`GET /api/processing?date=YYYY-MM-DD` 按北京时间提供固定版本；HTTP 导出与 MCP `read_processing` 可带相同 `version` 读取原结果。

各阶段采用自身证据和单位：收到带拾取起点的回执、接收分块请求、重复分块或提交、事务完成的快照、去重解析记录、实际物化的指标结果版本、实际完成的日报版本。不是把同一个 snapshot 数重复填到每个阶段。读取 Token 覆盖使用 #34 的相同确定性指标服务，因此该读取实际生成的指标版本也计入指标阶段。旧观察覆盖从迁移时的 `observedSince` 起记录。

#36 回执新增可选 `timing`，没有第二套回执协议。采集器在读取原生材料前记录进程实例 UUID 和单调时钟起点，冻结到本地待传计划；校验服务器可读 ACK 后冻结耗时并通过原 durable outbox 补送。队列在同进程下一轮重开仍能计算；进程重启后 UUID 不同，耗时为 `null`，绝不使用文件 mtime、来源时间或两台机器墙钟相减补值。旧回执仍可接受。

P95 以该日服务端收到的同进程测量回执为样本，用离散 95 分位；名称明确为“拾取 → 可读确认”，包括排队、上传与 ACK 传输，是原文可读时间的上界。页面展示样本数、没有测量的快照数以及 60 秒目标对应的毫秒值；无样本显示未记录。真实离线观察和计时是否可用分开，跨进程补传仍有断连次数与谱系记录。

当前待处理原因按现有快照、状态及原因类别聚合，数量有界；从原因入口可查看全部当前待处理快照，不受当前日期限制。具体原件引用与完整原因在审计面板内。Token 覆盖按 Agent 区分已知和未知，统一目录来自 #34，不引入未实现的营销指标。

尚未 ACK 的本地积压从既有设备同步报告展示份数、字节数、设备数及最近收到时间，链接回设备同步状态。它是最近收到的队列观察；不将缺少回执的拾取冒充已完成，也不将客户端完全断网期间服务器无法收到的信息补成虚构计数。
