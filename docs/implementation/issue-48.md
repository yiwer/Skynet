# 员工画像（#48）

状态：服务与 MCP 纵切已验证；Web 和独立集成验收正在推进。本记录不代表 AC-32、真实试点或 V2 总体验收通过。

## 固定画像

`GET /api/capability-profiles/:employeeId` 将同一员工、周期与权重方案的评估、用量、会话产效、活动以及日周报告来源冻结为一个画像版本。`period` 和 `preset` 沿用评估服务；`version` 指画像版本，`assessmentVersion` 用于来自员工列表的固定评估入口。

画像直接使用评估记录的 `inputs.usageVersion`，会话明细的指标版本必须与 `inputs.metricsVersion` 一致。读取组合前后检查语义输入身份，并额外检查设备状态、日周报告版本及刷新状态；连续变化时返回 409，不保存混合来源的画像。该检查包括原件、归属、有效分析及覆盖变化，不依赖缓存时间或快照数量。

已冻结的画像以追加记录保存。固定读取、导出、重启后读取不会重新查询当前设备信息或工作报告。旧评估已有完整画像时可定位保存结果；旧评估尚未冻结完整画像、且当前输入已变化时返回 409，固定评估本身仍可读取，不使用今天的报告补造历史画像。

页头按员工 ID 查询设备，避免同名人员混淆。最近同步来自原件成功提交时间，不使用心跳替代。任何设备接入日期未知时，员工接入边界保持未知。领域目前没有员工岗位字段，因此不以平台权限冒充岗位。

## 共享数值与工作来源

- 会话、提示词、工具调用、Token、代码与已验证结果直接来自固定用量报告；未知字段保持 null，已知部分另存。
- `UsageDailyPoint.outputs.verified` 按贡献引用的原事件来源日期归属。跨日会话不会把会话总产出复制到每一天；旧用量版本没有该字段时保留未知。
- 会话明细及任务分布来自固定会话产效报告；保留 Token、已验证、产效比分子/分母、返工、等待占比和对话链接。
- 工作内容读取现有日工作视图与周工作视图的全部固定分页。相同日报条目在周视图重复出现时合并显示，并保留两个来源。周范围始终为周一至周日，画像只纳入范围内条目。
- 读取画像不会请求生成报告或启动模型。尚未生成、排队和待刷新的报告保留真实状态。
- 最近活动按实际有活动的来源日期倒序读取，保存原事件和固定活动版本；最多保存最近 20 条并标记是否有更早活动。

## 分页与 MCP

HTTP 与 OAuth MCP `get_capability_profile` 调用同一查询服务。`pages` 为 daily、devices、sessions、work、reports、activity 分别给出 total、offset、nextOffset。首页每部分最多 20 项，内容较长时按字节减少；后续页须携带同一画像 version、section 和 offset。评估的分析输入引用分页继续使用已有固定评估接口。

画像响应为 MCP JSON 转义保留空间；完整 `/export` 保留全部内容，上限 16 MiB，并拒绝静默混用分页参数。完整重算使用 `POST /recompute`，不会覆盖旧画像。

Web 的 `#profile?...&version=` 仍表示固定评估；完整画像使用独立 `profileVersion`，避免改变既有员工列表与历史评估链接。
