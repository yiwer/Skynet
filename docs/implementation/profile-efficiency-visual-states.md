# 能力维度表格与产效未知状态

能力维度支持图表、表格两种展示。表格逐项显示同一固定评估的六维本人得分和团队中位数，沿用图表取整规则；缺失分数显示“未知”。表模式下点击强项或优先提升，返回对应维度的展开指标并移动焦点。切换按钮使用已有主题分段控件。

产效分布没有任何已知样本时显示紧凑状态和未知会话数量，保留表格、会话明细及原始对话入口。判定依据完整固定分布的已知数量，不依赖异步会话摘要是否完成；已知零仍为图点，混合数据继续展示分布图。

## 校验

通过真实 HTTP 上传与确定性分析形成测试输入，再从公开页面操作；未替换 API 响应。

- `assessment-dimension-table.test.ts`：同一固定评估六维分数与团队中位数逐项对应、键盘切换、320/390/768/1280/1920px 明暗主题、无页面外层滚动。
- `efficiency-unknown-web.test.ts`：全未知紧凑状态、未知数量和原句入口、已知零与混合数据、范围切换后 tooltip、相同十种布局。

两个行为均先在原实现观察到失败后实现。证据在工作区外 `Skynet-evidence/v2-2026-10-04/54-visual-states/`；这两项通过不代表 AC-31 的所有图表均已验收，也不代表 AC-32 性能通过。
