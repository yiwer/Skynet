# #50 复核备注

对应 [Issue #50](https://github.com/yiwer/Skynet/issues/50)、PRD v2 US 161 / 172、AC-16 / AC-37。使用已确认的公开上传、HTTP、OAuth MCP、Web 和导出边界进行验证。测试数据均为隔离的合成会话；结构化分析使用既有 Analysis 边界替身，本票未启动真实付费模型或读取员工材料。

## 行为

- 员工画像提供复核备注列表和追加表单。备注保留平台作者、服务器生成的北京时间和所附不可变评估版本；正文按纯文本呈现，可点击查看该评估。
- 沿用 ADR-0002，正常已认证用户可以对任意员工画像追加和读取备注；不要求身份维护权限。设备凭据、接入凭据和停用读取凭据不具备该写入身份。调用者不能自填作者或时间。
- 已保存内容没有修改、覆盖或删除接口。重复提交同一作者的 `requestId` 返回原记录，重新使用该编号保存不同正文、员工或评估版本返回 409。并发不同提交各自保留。
- 备注只写入独立的 `review_notes` 表，不进入分析、指标或评估输入；不改变评估版本、指数、等级、维度、证据或模型输入版本，不触发通知或人事动作。界面保存成功后只更新备注列表。
- 备注每条最多 2,000 字符，每页最多 10 条。游标固定员工、已提交追加上界与上一页位置；新追加不会混入当前翻页，刷新可读取最新记录。每员工追加事务串行分配列表位置，避免尚未提交的低序号被翻页遗漏。
- 表单在失败时保留正文和提交编号，支持键盘重试。备注正文有独立滚动区域，沿用平台主题、44px 操作区域、320px 窄屏和画像内部滚动，不增加外层页面滚动。

## 接口

| 入口 | 内容 |
| --- | --- |
| `GET /api/employees/:id/review-notes?cursor=…` | 共享读取，返回 `employeeId / notes / count / nextCursor` |
| `POST /api/employees/:id/review-notes` | `{ requestId, assessmentVersion, text }`，201 返回保存的记录；作者和北京时间来自服务器 |
| MCP `read_review_notes` | 与 HTTP 使用同一查询服务、同一分页游标；OAuth `archive:read`，只读工具 |
| Web `#profile?employeeId=…&version=…` | 复核备注表单、分页列表及所附评估固定链接 |

迁移在评估表就绪后运行。`review_notes` 引用员工及已有 `assessment_revisions`，独立保存作者当时的姓名；身份停用后其他已认证用户仍可查看既有记录。不存在对应员工或评估归属不符时返回 404，严格合同拒绝伪造作者、时间、控制字符和超长正文。
