## Behavior after the change

The original points, intervals, medians, axes and fixed source coordinates remain unchanged. Each row has non-overlapping touch cells of at least44 CSS pixels. A cell opens all its records or sessions; it does not aggregate their business values or hide coincident sources. An interval remains available in every cell it spans. Details are constructed only for the active cell.

Activity details show event type, original time, project, Agent, stable session ordinal within the fixed lane and original line/block. They use complete lane identities, not the possibly paginated event list. Point identity uses its logical session; waiting evidence is matched by exact original coordinates. Resizing or replacing the activity page closes obsolete cell contents. Each destination retains the API's complete fixed conversation/source link.

Efficiency details preserve each known value and its verified-result numerator/Token denominator, and explicitly select one session. Known zero remains a real point; unknown sessions retain the existing unknown table/state. Original conversation and segment navigation remain available after selection. Plotting still reads bounded fixed summary pages, never an automatic full export.

The existing chart disclosure hook supplies mouse/focus/explicit activation, Escape, internal popup scrolling and placement within the reading area. Its dialog parameter now also accepts an accessible label; prior boolean behavior remains unchanged. CSS changes are scoped: the wait marker and legend share a theme-derived contrast adjustment, reduced motion disables efficiency transitions, and the distribution card permits its popup while the inner chart and page retain their own scrolling and clipping.
